# Base de conocimiento editorial

Guardar aquí solo hallazgos aprobados o en revisión, nunca capturas, volcados completos, perfiles personales ni datos identificables.

Formato recomendado de archivo:

`[AAAA-MM-DD]-[perfil]-[tema]-[id].md`

Cada archivo debe usar `finding-template.md` y conservar la fecha, el nivel de evidencia, la fuente y las limitaciones. Un hallazgo no aprobado no puede alimentar copy público, puntuaciones, rankings ni automatizaciones.
