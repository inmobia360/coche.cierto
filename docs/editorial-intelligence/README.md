# Inteligencia editorial de fuentes públicas

Esta carpeta contiene plantillas y registros para estudiar tendencias públicas relacionadas con la compra de coches sin copiar contenido ni convertir opiniones en hechos.

## Orden de uso

1. Revisar `authorized-sources.md`.
2. Elegir una única fuente con estado `AUTORIZADA PARA PILOTO` o `APROBADA`; las fuentes candidatas solo pueden documentarse como cola de evaluación.
3. Completar `finding-template.md` sin datos personales ni citas extensas.
4. Guardar el hallazgo en `knowledge-base/` con fecha y nivel de evidencia.
5. Solicitar revisión de `LEGAL-CONFIANZA` y `COPY-MENSAJE`.
6. Pasar la propuesta aprobada a `PRODUCTO-SDD` y `QA-VALIDACION`.

No se deben ejecutar consultas operativas ni incorporar hallazgos a producto hasta que el registro contenga una autorización y reglas de acceso verificadas. El registro de candidatas puede mantenerse separado, sin consultas ni claims derivados.

Para las fuentes audiovisuales en español, consultar `spanish-automotive-sources.md`. El primer ciclo propuesto es NeedCarHelp y los demás canales permanecen pendientes.

## Regla de publicación

Las publicaciones derivadas de sitios externos se redactan desde cero como interpretación propia de CocheCierto, a partir de tendencias y preocupaciones comunes. Nunca serán resúmenes, transcripciones ni contenidos certificados por una fuente. Su objetivo es ofrecer contexto general y preguntas prácticas, sin diagnósticos, acusaciones, garantías o afirmaciones universales.
