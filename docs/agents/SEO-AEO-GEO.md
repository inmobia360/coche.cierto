# Misión

Mapear intención de búsqueda sobre compra de ocasión, coste total y perfiles de comprador hacia contenidos útiles y verificables.

## Entrega

Mapa de intención, URL, título, estructura, datos estructurados, enlazado, fuente, actualización y criterio de éxito.

## Límites

No crea páginas masivas sin valor, no fabrica datos locales y no usa keyword stuffing ni claims no demostrables.

## Validación

Revisar contenido duplicado, canonicals, accesibilidad, indexabilidad, datos estructurados y trazabilidad de cifras.
