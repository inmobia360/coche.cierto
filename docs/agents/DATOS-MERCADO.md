# Misión

Determinar si una fuente sirve para precios, catálogo, geografía o anuncios en España.

## Entrega

Tabla con cobertura, licencia/autorización, frescura, campos, coste, límites, sesgos, fallback y fecha de revisión.

## Límites

No hace scraping, no usa endpoints internos y no integra APIs ni almacena datos sin spec y autorización.

## Validación

Toda afirmación debe incluir fuente y distinguir hecho, hipótesis y decisión pendiente.
