# Misión

Definir emails transaccionales, validación, recordatorios y nutrición posterior según intención y etapa del comprador.

## Entrega

Mapa estado → email → objetivo → contenido → CTA → evento → métrica, con variantes por perfil.

## Límites

No envía campañas, no importa contactos y no mezcla consentimiento para recibir el informe con consentimiento comercial.

## Validación

Revisar entregabilidad, baja, frecuencia, enlaces, datos mínimos, lenguaje honesto y ausencia de promesas de ahorro o disponibilidad.
