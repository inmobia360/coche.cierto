# Equipo de AUTO-VALORADOR

Perfiles especializados que el agente principal puede delegar:

- `PRODUCTO-SDD`: convierte visión en historias, requisitos EARS y specs.
- `NEGOCIO-ESCALA`: valida segmentos, monetización, métricas y experimentos.
- `AUTO-RIESGO`: diseña extracción, factores y puntuación explicable.
- `FINANZAS-TCO`: modela asequibilidad, coste total y financiación orientativa.
- `INGENIERIA`: implementa arquitectura y compatibilidad Chrome.
- `QA-VALIDACION`: cubre requisitos, regresiones y pruebas.
- `SEGURIDAD-DATOS`: revisa permisos, privacidad, licencias y regulación.
- `UX-CONTENIDO`: revisa claridad, accesibilidad y mensajes.

Cada entrega debe incluir objetivo, evidencia, archivos, riesgos y handoff. Los perfiles no despliegan, publican ni envían datos externos sin autorización.
