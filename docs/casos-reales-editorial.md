# Casos reales — modelo editorial

`Casos reales` funciona como una sección de orientación práctica. El contenido puede partir de dudas frecuentes o señales públicas, pero cada publicación debe ser una interpretación propia de CocheCierto y no un resumen, transcripción o certificación de una fuente externa.

## Flujo obligatorio

`Hallazgo → clasificación por perfil → verificación → revisión legal/editorial → publicación → revisión de frescura`

Antes de publicar, cada pieza debe tener:

- Título y resumen claros.
- Perfil y etapa de compra.
- Problema concreto del comprador.
- Señales o datos que el usuario puede comprobar.
- Acción recomendada y límites.
- Recursos internos relacionados.
- Fecha de publicación y próxima revisión.
- Nivel de evidencia y fuentes internas de trabajo.
- Disclaimers adecuados.

## Estados

`BORRADOR`, `EN_REVISION`, `APROBADO`, `PUBLICADO`, `RETIRADO`.

No se publica automáticamente. Los temas legales, técnicos, de seguridad, precios o fiabilidad requieren contraste con documentación oficial o técnica independiente antes de mostrarse como contexto.

## Perfiles iniciales

`primera-compra`, `cambio-coche`, `familiar`, `uso-profesional`, `presupuesto-ajustado`, `coche-ya-visto`.

## Regla de lenguaje

Explicar primero qué significa para una persona normal y después qué debe hacer. No usar opiniones externas como autoridad, no identificar particulares ni vendedores y no afirmar que una unidad es segura, fiable o adecuada sin verificación profesional.
