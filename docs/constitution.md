# Constitución de CocheCierto

1. **Especificación antes que código.** Todo cambio funcional debe tener una spec aprobada, alcance definido y criterios de aceptación claros.
2. **Decisiones explicables.** Cada diagnóstico, recomendación de encaje o cálculo de TCO (Coste Total de Propiedad) debe mostrar factores, supuestos y fuentes con total transparencia.
3. **Incertidumbre honesta.** La ausencia de datos nunca equivale a buen estado mecánico o documental; la herramienta no sustituye una inspección pericial presencial ni un informe oficial de la DGT/registro.
4. **Independencia comercial.** Patrocinios, acuerdos de afiliación o captación de leads jamás alterarán de forma silenciosa ni sesgarán el ranking técnico o las recomendaciones al comprador ("No vendemos coches. Te ayudamos a elegir el correcto").
5. **Privacidad, consentimiento y seguridad.** Minimización estricta de datos personales, cumplimiento normativo (RGPD/LOPD) y uso exclusivo de fuentes e integraciones autorizadas.
6. **Calidad y verificación rigurosa.** Cada funcionalidad debe contar con pruebas automatizadas o comprobaciones documentadas antes de darse por completada.
7. **Escala sostenible y modular.** Priorizar MVPs medibles y arquitectura desacoplada (Frontend / Backend API / Motor de TCO), validando la demanda real en cada fase.
