# Constitución — coche.subasta

Principios no negociables. Toda spec, plan, tarea y cambio debe cumplirlos.

1. **La spec manda**: no se implementa comportamiento que no esté especificado y aprobado.
2. **Decisión auditable**: cada recomendación debe mostrar datos, supuestos, fórmula, riesgos e incertidumbres.
3. **Riesgo antes que promesa**: nunca se presenta una estimación como tasación oficial ni como rentabilidad garantizada.
4. **Coste completo**: compra, impuestos, comisiones, transporte, documentación, reparación, contingencia y venta deben estar separados.
5. **Fiscalidad verificable**: las reglas españolas se comprueban con fuentes oficiales o asesoría; no se inventan tipos ni requisitos.
6. **Automatización prudente**: no se automatizan pujas, compras, pagos ni aceptaciones vinculantes.
7. **Tests como puerta**: cada tarea termina con validaciones reproducibles en verde antes de avanzar.
8. **Cambios trazables**: primero se actualiza la spec, después el plan/tareas y finalmente el código.
