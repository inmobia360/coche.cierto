# SUBASTA

MVP de una extensión Chrome para analizar oportunidades de compra de vehículos de ocasión en subastas, empezando por Auto1.

## Primera entrega

- Ranking de menor riesgo para los vehículos visibles en una lista.
- Diagnóstico dentro de cada ficha.
- Extracción de kilometraje, año, precio, accidentes, daños, prueba dinámica, mantenimiento, llaves, emisiones, COC y devolución Premium.
- Puntuación explicable de 0 a 100. Un valor bajo indica menor riesgo orientativo.
- Configuración de kilometraje y antigüedad de referencia.

## Probar en Chrome

1. Abre `chrome://extensions`.
2. Activa **Modo de desarrollador**.
3. Selecciona **Cargar descomprimida** y elige esta carpeta.
4. Abre o recarga Auto1.

## Próximo desarrollo recomendado

1. Añadir formulario de costes: comisión, IVA/régimen, transporte, documentación, reparación y contingencia.
2. Añadir precio de venta prudente/base/favorable con comparables fechados.
3. Calcular precio máximo de puja y margen mínimo.
4. Guardar oportunidades y resultados reales.
5. Integrar fuentes adicionales únicamente mediante APIs, exportaciones o accesos autorizados.

La herramienta no sustituye asesoramiento fiscal, inspección mecánica ni comprobación documental. No automatiza pujas ni compras vinculantes.
