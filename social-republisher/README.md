# CocheCierto · Social Repost asistido

Extensión Chrome Manifest V3 para preparar republicaciones con texto, enlace y UTMs por canal.

## Uso

1. Abre `chrome://extensions`, activa el modo desarrollador y carga esta carpeta.
2. Crea un borrador desde el popup.
3. Pulsa **Copiar y abrir destino**.
4. Revisa el contenido y las normas del destino y confirma manualmente la publicación.

La extensión no publica automáticamente, no raspa grupos y no accede a contactos. Para páginas propias puede añadirse un adaptador de Meta Graph API en una fase posterior, con permisos aprobados.

## Flujo para grupos

Guarda cada grupo con nombre y URL, selecciona los destinos y pulsa Preparar para grupos. Cada grupo recibe un envío pendiente independiente. Abre, pega, publica manualmente y marca Realizado para evitar duplicados.
