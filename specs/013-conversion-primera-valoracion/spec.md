# Spec 013 — Conversión a primera valoración y registro progresivo

## Objetivo

Guiar al visitante desde la página de inicio hasta una primera valoración útil y permitir que guarde el resultado mediante un registro progresivo, sin pedir datos antes de demostrar valor.

## Flujo aprobado

```text
Inicio → situación → preguntas → orientación inmediata → email opcional para guardar → validación → informe
```

## Requisitos

- El hero explica qué recibe el usuario y cuánto tarda.
- El CTA principal usa siempre `Crear mi valoración gratuita`.
- El usuario puede comenzar sin cuenta ni email.
- La orientación aparece antes de solicitar el email.
- El email se solicita únicamente para guardar o recibir el informe.
- El consentimiento del resultado está separado del consentimiento comercial.
- El teléfono es opcional y no se pide sin una función que lo justifique.
- El usuario puede revisar respuestas sin perder el progreso.
- El sistema comunica si el envío o validación no está disponible.
- La demo y los recursos funcionan como alternativas para usuarios que aún no están preparados.

## Copy base

> Responde unas preguntas sencillas sobre tu uso y presupuesto. Recibirás una orientación práctica para saber qué comparar y qué comprobar antes de comprometer tu dinero.

> Primero verás tu orientación. Solo te pediremos el email si quieres guardar el informe.

## Medición

Medir inicio, avance, abandono por pregunta, finalización, resultado visto, email introducido, consentimiento, email validado, informe abierto y recurso consultado.

## Fuera de alcance

Registro obligatorio al inicio, contraseña obligatoria, teléfono obligatorio, urgencia artificial, promesas de certeza mecánica y campañas comerciales mezcladas con la entrega del informe.
