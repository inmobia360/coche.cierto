# Validación — Spec 012

- [ ] Cada enlace contextual llega al recurso correcto.
- [ ] El usuario puede previsualizar antes de descargar.
- [ ] El formulario conserva sus datos al volver desde la vista previa.
- [ ] No hay desbordamiento horizontal en móvil, tablet o escritorio.
- [ ] Los documentos muestran fecha, límites y enlace a Recursos.
- [ ] Los botones tienen texto claro y estado accesible.
- [ ] El modo claro/oscuro se conserva entre páginas.
- [ ] No se solicitan datos personales para una guía básica.
