# Spec 003 — Informe estratégico de compra

## Objetivo

Transformar el resultado del diagnóstico en una guía accionable: qué solución de movilidad encaja, cuánto debería reservar el usuario, cómo comprar con prudencia, qué riesgos revisar y cómo pueden cambiar sus necesidades en el futuro.

## Resultado para el usuario

El informe se entrega después del diagnóstico y antes de solicitar el contacto. Debe poder entenderse en menos de diez minutos y terminar con un siguiente paso claro.

## Secciones obligatorias

- RF-1: EL SISTEMA mostrará un resumen con recomendación principal, nivel de confianza, principal riesgo y decisión sugerida.
- RF-2: EL SISTEMA comparará tres escenarios: económico, equilibrado y menor incertidumbre.
- RF-3: EL SISTEMA separará precio del vehículo, gastos iniciales, coste de uso y reserva de emergencia.
- RF-4: EL SISTEMA mostrará presupuesto máximo de compra, presupuesto total recomendado y umbral de abandono cuando los datos lo permitan.
- RF-5: EL SISTEMA explicará estrategia de compra: ocasión/nuevo, contado/financiación, negociación y momento de revisar la operación.
- RF-6: EL SISTEMA generará un checklist personalizado de documentación, prueba, mantenimiento, garantía e inspección.
- RF-7: EL SISTEMA mostrará una perspectiva de 3–5 años sobre uso, ZBE, espacio, reventa, depreciación y cambios previsibles.
- RF-8: EL SISTEMA distinguirá datos declarados, estimaciones, hipótesis y datos pendientes.
- RF-9: SI el presupuesto total es bajo o no existe colchón, ENTONCES EL SISTEMA advertirá de puesta al día y reparaciones sin avería ficticia concreta.
- RF-10: EL SISTEMA ofrecerá guardar o recibir el informe y un siguiente paso opcional: analizar anuncio, comparar opciones o solicitar ayuda.
- RF-11: SI la intención es cambiar de coche, EL SISTEMA ofrecerá opcionalmente valorar el vehículo actual y mostrará un rango orientativo antes de pedir contacto.
- RF-12: EL SISTEMA mostrará una vista parcial útil y solo desbloqueará el informe completo después de validar el email, manteniendo separado el consentimiento comercial.

## Escenarios

### Económico

Prioriza coste inicial y coste fijo. En ocasión puede partir desde 3.000 €, pero siempre suma transferencia, seguro, puesta al día y reserva mínima.

### Equilibrado

Equilibra precio, fiabilidad, coste total, seguridad, uso y reventa.

### Menor incertidumbre

Prioriza garantía verificable, historial, disponibilidad, menor probabilidad de gastos inesperados y una compra más predecible.

## Reglas de confianza

- No mostrar una valoración exacta sin fuente y fecha.
- No afirmar que una unidad está bien mecánicamente sin inspección profesional.
- No calcular solvencia ni aprobar financiación.
- Mostrar qué respuesta del usuario podría cambiar la recomendación.
- No ordenar resultados por patrocinio.

## Adaptaciones

### Ocasión privada

Enfatizar precio justo, historial, cargas, ITV, garantía, prueba, diagnosis y reserva de reparación.

### Ocasión profesional

Enfatizar coste/km, disponibilidad, carga, tiempo de parada, fiscalidad orientativa, imagen profesional, financiación y posibilidad de renovación.

### Nuevo

Recorrido preparado para una fase posterior: garantía, configuraciones, depreciación inicial, renting, financiación y TCO.

## Criterios de finalización

El informe presenta las secciones obligatorias, funciona con presupuesto bajo y desconocido, identifica supuestos, ofrece checklist y permite continuar sin contacto o solicitarlo con consentimiento separado.
